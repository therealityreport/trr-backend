## Comparison contract

- Match old and new statements through `measurement_key`, not query ID.
- Use the same parameter class and response/row semantics for the comparison.
- Record replacement query IDs only after the changed code is deployed and exercised.
- Pass when execution time or shared-block work improves by at least 80% with no worse temp spill and all response fixtures remain equal.
- Report route latency separately from statement latency.

## Route timing sources

- Backend: `trr_api_http_request_duration_seconds` by normalized route/method/status.
- Next admin proxy: `Server-Timing`, `x-trr-admin-route-ms`, backend/database timing headers, and `[admin-route-timing]` logs.
- Browser: existing admin load samples for profile and social landing.
- Split cache hit, miss, and stale cohorts and report sample count plus P50/P95/P99.

Accepted 2025+ completion SQL now uses typed ownership/count fields and no raw payload extraction or `jsonb_to_record`. The sidecar statement performs only two lateral PK-existence checks and does not select payload JSON. ## Timing-source readiness audit

- Backend route timing exists and is recorded by normalized route/method/status in `trr_api_http_request_duration_seconds`; `/metrics` exposes the Prometheus histogram.
- The catalog, completion, snapshot, and landing Next routes attach admin timing. The timing helper emits `Server-Timing`, `x-trr-admin-route-ms`, optional backend/database timing headers, and cache status in `[admin-route-timing]` logs.
- Browser `admin-load-samples` currently stores at most 50 local samples per surface. Profile and landing surfaces write samples, but the catalog fetch itself has no dedicated sample and there is no checked-in percentile/export/24-hour aggregation command.
- `perf:admin:api` can benchmark an explicit `https://admin.trr.localhost/...` route and writes autocannon P95/P99 artifacts, but it does not by itself separate cache hit/miss/stale cohorts or provide a 24-hour production soak.

## Gates still open

- Sync still lacks an exercised replacement fingerprint. The 100-shortcode incomplete-target sample is directional and needs representative larger batches.
- Exact count P95 under 500 ms is not proven by cumulative statement statistics; the observed page-window max is 672.7 ms and fallback max is 531.8 ms.
- Warm 2025 compare remains above the 2-second route target at 3.984-4.286 seconds. The 9.340-second cold-start outlier also exceeds 5 seconds and remains explicitly recorded.
- The three 2026 legacy-only samples are under 2 seconds, but route P95, cache-cohort sample counts, and browser-perceived catalog P50/P95/P99 are not yet established.
- The 24-hour compare soak, zero required mismatches, sidecar read cutover, and 24-hour/7-day statement/route/DB/Modal rechecks remain pending.
